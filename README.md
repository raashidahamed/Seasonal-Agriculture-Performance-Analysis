# Seasonal-Agriculture-Performance-Analysis

## Project
VOIS AICTE Batch 1 (2026–2027) – Major Project

## Contents
- `Seasonal_Agriculture_Performance_Analysis.ipynb` – complete analysis notebook
- `seasonal_agriculture_performance_cleaned.csv` – cleaned dataset
- `Seasonal_Agriculture_Performance_Analysis_Report.docx` – detailed report
- `Seasonal_Agriculture_Performance_Analysis_Report.pdf` – PDF version of the report
- `Completed_Annual_Review_Presentation.pptx` – filled annual review presentation
- `season_summary.csv`, `crop_summary.csv`, `irrigation_summary.csv`, `state_summary.csv` – analytical summaries
- `charts/` – figures used in the report and presentation

## Google Colab
1. Open Google Colab.
2. Upload `Seasonal_Agriculture_Performance_Analysis.ipynb`.
3. Upload the supplied CSV when prompted by the first data-loading cell.
4. Run the notebook from top to bottom.

The notebook automatically checks for the supplied CSV filename and, if it is not found, opens the Colab upload dialog.

## Main analysis
- Data quality and cleaning
- Seasonal comparison
- Crop comparison
- Irrigation analysis
- State comparison
- Spearman correlation analysis
- Kruskal–Wallis tests
- Evidence-based findings and recommendations
